# 0.14.0 EQ 收藏（2026-10-21）

## 使用

1. 打开“自定义 EQ”，载入风格文件、本地预设或调整自己的曲线。
2. 点击“☆ 收藏这条 EQ”；如果曲线尚未保存或有修改，按钮显示“☆ 保存并收藏当前曲线”，同时保存名称及十段增益。该操作不会启用或改变正在播放的音效。
3. 已收藏的曲线显示“★ 取消收藏”。取消仅移除收藏标记，保留本地预设及当前音效。
4. 页首“收藏的 EQ”可以载入收藏项，仍需单独应用到手机EQ。风格库与本地列表也会显示星标。
5. 通知“切换声音模式”面板将收藏项置顶，并提供“仅显示收藏”开关；选择预设才会配置手机音效。空收藏时可点“管理收藏”进入自定义EQ页。

## 数据与兼容

- 收藏和通知筛选保存在原有本地预设SharedPreferences中。旧版本没有这些字段时按未收藏处理，原预设JSON结构不变。
- 本地预设使用稳定ID关联收藏，重命名或修改曲线后仍保留收藏。风格预设使用资源文件名关联，排序和显示名称变化不会导致误关联。
- 收藏风格文件不会额外复制为本地预设。尚未保存的曲线收藏时才新建本地预设，仍遵守最多20个本地预设的限制；已有预设修改与收藏可一并提交。
- 保存曲线和新增收藏使用同一次偏好提交。删除本地预设会同时清理对应收藏标记，保留其他本地与风格收藏。
- 使用共享偏好监听刷新界面；当前音效的选中态按服务回传曲线匹配，不按收藏排序后的旧索引推断。筛选掉当前音效时不会自动切换到其他预设。
- 开启“仅显示收藏”不会停止或替换正在运行的曲线。无收藏时有明确空状态，并保留停用EQ入口。

## 验证范围

现有350项协议、几何、曲线与导入主机检查通过；这些测试不覆盖Android收藏偏好存储和触控。编译及APK签名另行核验。本机未连接Android设备，收藏持久化、通知筛选和实际点按仍需实机确认。
