# ZirconPods 0.8.1：截图式通知与 10 秒流体云

## 0.8.1 修正

自绘卡片和分组底色透明，按钮半透明，透出系统通知背景。系统图标、应用名称与展开控件仍由 Android/ColorOS 提供，无法由普通应用移除。详见 毛玻璃通知修复说明.md。

## 折叠通知

按第一张参考图组织为“锆势产品图 + 耳机名称 + 充电盒/左耳/右耳电量”，下方为“切换声音模式”和“断开连接”两个圆角按钮。耳机图跟随应用中黑、银、紫配色；不会使用参考图中的 i7 名称、产品或电量。

“切换声音模式”直接打开私有的 Miuix 快捷控制对话框 Activity，可选择四模式；该入口无需悬浮窗权限。“断开连接”沿用原服务的手动断开逻辑，会暂停自动连接。通知空白/设备头部进入完整应用。

Android 对折叠自定义内容可能只提供 48dp，因此在这个高度内排列两行。系统应用名称、展开箭头、通知外框与字体缩放由系统处理，不声称逐像素复刻截图。

## 展开通知

向下展开通知后，独立的 244dp RemoteViews 显示居中设备名称、三列电量与电池图标、降噪/风噪/通透/普通四个直接控制按钮、降噪等级、更多/完成。

- 选中态仅跟随当前连接中耳机已确认的回包；请求期间显示等待信息。
- 降噪等级只开放已确认的“标准降噪”和“极限降噪”，不编造参考 i7 的轻度/深度协议。非降噪状态时显示“未开启降噪”，无法设置等级。
- 更多进入完整控制界面；完成通过通知直接启动并结束短暂的私有 Activity 来结束本次交互，不断开耳机、不停止前台服务。具体收起动画由 SystemUI 决定，尚待 ColorOS 实测。没有使用受限制的 CLOSE_SYSTEM_DIALOGS 广播或隐藏状态栏 API。
- 原生通知展开由系统箭头/下拉手势控制；应用不能通过公开 API 强制展开通知。

## 流体云

连接提示与折叠通知共用耳机名称、产品缩略图和电量文字；不包含切换模式、断开连接或其他操作按钮。短胶囊文字优先显示充电盒电量，否则显示左耳电量或“已连接”。

连接完成后保持 **10 秒**，从本次成功连接开始单次计时，电量回包不续期；失败、断开、手动关闭或关闭功能仍会立即移除。连接过程中保留真实不确定进度。没有用常驻快捷通知冒充实时更新任务。

原生实时更新采用受支持的标准 BigTextStyle 和 large icon，不能使用自定义 RemoteViews 强制复刻第一张图的左右排列。ColorOS 决定其胶囊与展开卡片外观，应用调整的是耳机图、名称、电量和操作项。实际是否提升为流体云仍由系统决定；设置页继续展示授权、API 与提升结果。

## 验证

184 项主机检查通过（77 协议、22 通知状态、19 连接提示、43 自动连接/磁贴、23 共用卡片内容与计时边界）。APK 经 release 编译、v2 签名与 zipalign 检查。新快捷面板不导出，不增加联网、悬浮窗、全屏通知、通知监听或无障碍权限。

未连接 Android 实机或模拟器；通知布局、按钮分发、完成操作、流体云排版与实际耳机控制尚待实机确认。

依据：[Android 自定义通知](https://developer.android.com/develop/ui/views/notifications/custom-notification)、[Android 实时更新](https://developer.android.com/develop/ui/views/notifications/live-update)。
