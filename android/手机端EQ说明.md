# 手机端十段 EQ（0.10.0 测试版）

用于在手机侧处理播放音频，绕开锆势0.3.1已知查询只返回普通ACK的问题。没有解锁耳机DSP、刷固件或向耳机写入自定义EQ。Android应用仍支持8.0+，手机音效引擎需要Android9/API28+。

## 使用

1. 连接锆势或其他蓝牙/有线耳机，打开主界面 → 自定义 EQ。
2. 选择本地预设或调整十段控制点，点击“应用曲线并启用手机 EQ”。默认使用“播放器会话”。保存预设只是写入本地列表，应用按钮才会更新当前手机音效。
3. 在启用后重新打开播放器播放音乐。会话模式只接入播放器公开的音频会话；仅暂停/继续可能沿用旧会话，此时可在播放器内选择“系统均衡器”，再选 ZirconPods。
4. 若一直显示等待会话，可选择“全局兼容（实验）”，再点击应用。模式互斥，不同时挂载全局与会话音效，避免叠加。全局可能因系统、硬件直出或播放器音频路径被绕过，参数回读成功也不等于所有歌曲都会经过音效链。
5. 页面显示音效是否创建、接入数量、当前曲线及自动输入余量。可在页面或手机EQ通知中停用；“复制手机 EQ 诊断”用于反馈系统拒绝、控制权丢失或没有听感变化的问题。

可以用明显的参考曲线与平直曲线切换试听。测试时先关闭其他均衡器，避免系统音效控制权冲突。该引擎对输入做负增益余量并启用限幅，提升频段后整体响度可能下降；这是留出余量的预期结果。

## 开源方案

移植并改写 [Equalizer314](https://github.com/bearinmindcat/Equalizer314) 的音效构建、先配置后启用和音频会话路由部分，固定提交 `90dd51a8f3e1333b7ffcfedba4e167ab3f250034`，GPL-3.0。授权原文、文件哈希和修改说明在 [third_party/Equalizer314/UPSTREAM.md](third_party/Equalizer314/UPSTREAM.md)，许可证同时包含在APK并可从设置 → 开源许可查看。

本次只移植引擎相关部分，不包含上游完整参数EQ、混响、AutoEQ数据库或隐藏API功能。也研究了OpenEQ与RootlessJamesDSP；后者通过音频捕获处理，存在捕获限制与额外延迟，本版未集成其音频捕获路径。

## 处理方式与生命周期

- 使用公开 `DynamicsProcessing` API，优先尝试64频带，失败时依次尝试32/10频带。
- 界面保留20/100/300/500/1k/2k/3k/5k/8k/15k Hz十个控制点，−6～+6dB、1dB步进；按对数频率插值到系统频带。DP频率参数是每段上截止频率，不能直接把十个控制点误当作十个上截止频率。
- 双声道配置，输入增益为负的最大正增益，限幅阈值−1dB、比率10:1、零补偿；系统请求频率分辨优先、40ms帧长。实际延迟及厂商实现需实测。
- 在启用前写入参数，之后读取频带数量、增益和截止频率核对。API接受配置只代表参数被接受，不作为对实际播放音频的测量结果。
- 正常优先级，不循环抢夺其他音效的控制权。服务监测到丢失控制时提示用户重试。
- 用户主动启动的独立前台服务持有音效，不依赖蓝牙控制socket；应用界面退出后继续运行。通知提供停用按钮。当前不在开机或进程被杀后自动启用，用户需重新开启。
- 服务存在期间接收播放器标准OPEN/CLOSE广播，最多保留16个会话。拒绝广播中指定的全局会话0；全局只能由本地显式选项启用。
- 系统检测不到蓝牙/有线/USB耳机输出时释放音效并等待设备连接。输出设备“存在”不等于每个播放器都实际路由到该设备，尤其是同时有多个输出时；此项不能作为精确输出路由或听感证明。
- 曲线和模式保存到本地；播放器会话只保存在内存。未添加网络、录音、无障碍或屏幕捕获权限，也不需要root或Shizuku。

## 验证范围

新增28项主机检查涵盖控制点、对数中点、频率边界、各后端频带映射、余量不超界、非法输入及状态快照隔离。连同此前260项，共288项通过。Release另校验编译、签名、对齐及APK许可资产。

没有连接Android实机/模拟器，无法在本机验证OPPO PGU110/Android16的原生音效实现、播放器会话广播、后台存活、页面触控或真实听感。该版本是集成完成的兼容性测试包，不能宣称已验证全局音效生效。

参考：[Android DynamicsProcessing](https://developer.android.com/reference/android/media/audiofx/DynamicsProcessing)、[AudioEffect 会话广播](https://developer.android.com/reference/android/media/audiofx/AudioEffect#ACTION_OPEN_AUDIO_EFFECT_CONTROL_SESSION)。
