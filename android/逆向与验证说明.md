# RoseLink 锆势本地控制：逆向与验证说明

本文件记录历史逆向与构建结果，历史版本体积、哈希、测试数与验证结论不代表当前版本。当前为 0.7.0，使用 Miuix 界面，共 161 项主机检查；当前功能与实机验证边界见 README。分析工作区中的 analysis/ 证据文件和原始反编译输出未随本仓库分发。

## 目标与范围

输入：用户提供的 `RoseLink-release.apk`。用户确认目标为 Android APK，设备为弱水时砂锆势，并优先完成本地耳机控制。

原包：RoseLink 3.8.1，versionCode 5389，包名 cn.ikaile.ruoshui.client，minSDK 26，targetSDK 36。SHA256：df2b5f1f6e54ad8d124b19ae105d3e1d5ed3fcd28a4f84f9c308bc8d06d688c0。

## 证据与方法

REA 成功完成 APK 包结构与 Flutter AOT 快照识别。保留证据 `analysis/rea-evidence.json`。

- 包结构父证据：ev_b16a95431289032f48ff748c9259145f43482dd49414a184df03b26a2e70225a。
- Dart AOT 父证据：ev_120f738a0ad1ef1d4f86863544ccd21d6fd7de793eac8948e46016f82bf4a382。
- 原包存在 ARM64 libapp.so/libflutter.so 与 Java/Dex；主要控制业务位于 Flutter AOT。
- REA JADX 分析被 Windows native self-test 的根目录共享错误阻断（Win32 32）。未修改全局 REA 配置。
- 后续使用 [DAE v0.1.13](https://github.com/ejfkdev/dae/releases/tag/v0.1.13) 静态解析；工具二进制 SHA256 dcd4bd8b3056068092bfe3321bc2c7957b2b7ad5c5e1758684c7c31f0d6f6443，与发布页一致。此部分是独立工具证据，不能称为 REA 反编译结果。
- 引擎字符串为 Dart 3.11.4，快照 hash 78da37fed6bf1489361a312568249f3f。DAE 选择同 hash 的 3.11.6 profile 并标记 unverified。函数地址、标量命令结合原始 ARM64 指令核对。
- DAE 数组显示层对旧 CID 的硬编码导致 ImmutableArray 未展开。`analysis/array-recover.cjs` 依据原始快照流与 debug fill 位置恢复对象引用；数组末端 0x315a7f、池末端 0x3b7fdc 均吻合。`analysis/array-focused.json` 保留重点列表。另有仅分析用副本修正显示的交叉结果，未将该副本分发为原软件。

## 实现与验证

全新原生 Java 界面与 RFCOMM 传输，无第三方运行库；仅发送已经映射的控制命令。异步连接使用 session 世代与目标流绑定，避免快速重连时旧命令写入新设备。控制状态只采纳校验后的回包。

30 项纯 Java 测试通过，包括固定命令帧、反向开关、选项范围、分包/合包、多段LTV、双校验变体、噪声重同步、校验失败不发布状态、电量位掩码、手势与固件解析、ACK拒绝。

构建成功，APK 37,343字节；v2/v3签名、zipalign和包名校验通过。SHA256：56ca3005babde3d54e83ea1d36ae38a90599ae352e09e17b7adff9c302a7143f。

## 尚未确认

没有连接的手机、模拟器或真实锆势，未验证 APK 安装启动、蓝牙握手、特定固件的实际控制效果。静态解析不能代替这些实机验证。Decoder 未实现原版的零长度LTV恢复变体，若设备返回该格式需依据实机日志补齐。降噪等级等高级功能因 UI 与 wire 映射尚未完整核对而未开放；无模拟成功或猜测性写入。
