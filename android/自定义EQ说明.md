# 十段自定义 EQ（0.9.0 测试版）

> 历史实现记录：0.12.0已移除下述耳机内置EQ实验诊断界面，当前仅提供手机端EQ编辑、风格文件和预设管理。本文保留原协议验证方法，不代表现行版本仍提供这些硬件读写入口。

## 0.9.1 实机反馈与诊断补充

用户提供的锆势固件0.3.1日志截图显示普通状态、电量、模式可正常返回；20:12:25发送 `FF 01 02 FA 3E 3A AA` 后，20:12:26只收到 `DD 01 02 FE 00 DE AA`，解码为 `FE 00` 普通确认，随后超时。该次查询没有观察到3E曲线，不是已经收到了曲线而界面未载入；也不能据一次ACK断定硬件永远不支持。

0.9.1在只读查询期间补充一次普通音效查询（1秒）以及一次有界的EQ只读重试（3秒），7秒截止；不重试写入，不自动切换自定义模式。EQ页面展示原始数据块/协议块/普通确认/3E数据计数，区分完全静默、原始包未解码、仅确认、有其他状态回包、3E长度或范围不符。

“复制 EQ 诊断”可复制本次通信、手机系统、设备型号和查询时固件信息；不添加蓝牙地址。每次操作最多48条、每个原始数据块最多128字节，完成或断线后保存快照，下一次操作才重置。新增15项诊断主机检查（包括用户截图中的真实ACK帧），总计260项通过。本版改进诊断，不代表固件0.3.1已能应用自定义EQ。

入口：主界面 → 超级大师调音分组 → 自定义 EQ。Miuix 页面按用户提供的 EarFeel i7 截图设计；用于锆势的十段控制仍需对应固件实测。

## 编辑与保存

- 频段标签：20 / 100 / 300 / 500 / 1k / 2k / 3k / 5k / 8k / 15k Hz。
- 每段 −6～+6 dB，1 dB 步进；可拖动或点击竖向滑杆，支持无障碍增益调整。
- 支持音效命名、保存修改、新建、删除（二次点击确认）、曲线归零。最多20个本地预设、名称最多40字。
- 内置截图中两条参考曲线：“土嗨（不盖人声）”与“极致人声”。名称只用于手机列表，不写入耳机。
- 本地保存与耳机应用是两步。离线可编辑和保存，不会自动发送蓝牙指令；选择预设、归零、删除也不会修改耳机。
- 耳机回读曲线单独显示，点击“载入回读曲线”才会覆盖编辑区。

## 锆势兼容性流程

1. 连接耳机，在 EQ 页面点“读取耳机 EQ”。这一步只发送查询。
2. 收到恰好十段、范围有效且外层校验通过的数据后，启用“应用到耳机（实验）”。普通 ACK、预设模式回包、错误长度及超范围数据不能启用。
3. 点应用只先写入曲线，500毫秒后查询回读。曲线不一致就停止，不切换自定义模式。
4. 回读与所选曲线一致后，才发送自定义模式指令；之后查询音效模式。只有耳机报告模式4，才显示“耳机已回读相同曲线，并报告自定义模式”。
5. 7秒未完成则显示未获得确认，允许重试。不把超时等同于“固件不支持”。断线和换设备清空能力数据及未完成事务，旧定时任务不能向新连接发送命令。

若始终不能读到十段数据，可在设置 → 诊断日志复制相关 TX/RX，并带上手机系统、耳机固件版本反馈。此时本地预设仍可使用，但不能宣称已改变锆势音效。命令回读也不等于听感、实际频点及断电保存已经测试。

## 静态证据及实现边界

原始对象为用户提供的 RoseLink-release.apk，SHA-256 `df2b5f1f6e54ad8d124b19ae105d3e1d5ed3fcd28a4f84f9c308bc8d06d688c0`；ARM64 libapp.so 为 `99187d5ff620701848c1e11f15b1a2a48752fccaa48bfdb8620ca308d8e1cf76`。

REA 身份证据：`ev_17a7bd56cd39acd4ff4087a50e16267f1769ffb1ad666c45d16a0af12eceb6c6`。当前原生提供器不可用，定点反编译使用已有 DAE v0.1.13，在相同哈希的库上复核原始 ARM64 指令。

| 原版地址 | 观察 | 本地实现 |
|---|---|---|
| 0xd572c8 | getCustomEq 返回 FA 3E（已校正 Dart Smi） | 手动只读查询 |
| 0xd573b8 | setEqCustom 返回 2A 04 | 曲线一致后选自定义模式 |
| 0xd56868 | setEqCustomData 添加3E和编码数据 | 十段写入 |
| 0xd56b40 | 输入 double 直接转整数，没有乘法缩放 | 1 dB整数步进 |
| 0xd56930 | 将绝对值填充为8位并将首位换为符号位 | 符号位+绝对值编码，非补码 |
| 0xf07088 / 0xbb95a4 | 自定义 EQ 接收、最高位符号/低7位幅度解析 | 严格十段校验 |
| 0x6d2830..0x6d2848 | 锆势配置只初始化预设列表，未显式开放自定义入口 | 明确标记实验，不自动批量探测/应用 |

这些方法属于共享 V2 协议，不能单凭代码中存在就推断锆势 DSP、频点映射和固件保存机制支持 i7 同等能力。界面频率标签来自用户截图；未经锆势实测确认。不刷固件、不修改官方 App、不注入系统音效。

## 验证

61项新增主机检查覆盖截图曲线的命令向量、所有增益档位、异常回包拒绝、分片解码、快照隔离，以及断线/超时/不一致/模式确认状态。原184项主机检查也通过，共245项。Release 构建另行校验签名和对齐；当前未连接 Android 实机或模拟器，页面渲染、触控体验和实际耳机音效仍需验证。
