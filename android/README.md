# ZirconPods 0.7.0

适用于弱水时砂锆势的 Android 本地控制工具，Android 8.0 及以上。

## 自动连接与控制中心磁贴

0.7.0 新增自动连接和系统快捷设置磁贴。首次手动连接成功后，默认记住该耳机的蓝牙地址；后续打开应用，或系统报告同一副耳机的蓝牙/音频连接恢复时，尝试建立本地控制连接。设置中可关闭自动连接。手动断开会暂停自动连接，直到手动连接或收到该耳机真实断开后重新连接的系统事件；不会反复扫描或无限重试。

进入右上角设置 → “添加耳机模式磁贴”，在系统确认框中添加；或下拉控制中心 → 铅笔 → 添加“耳机模式”。位置和大小由系统与用户编辑决定。点击磁贴按“降噪 → 风噪 → 通透 → 普通”循环，当前模式以耳机回包为准。断开时点击先连接已记住的耳机，不排队发送模式命令；尚未读取模式时只刷新。通知栏原有四个独立模式按钮继续保留。

ColorOS 可能限制后台启动，请允许附近设备和通知权限，并按需允许 ZirconPods 后台运行。被强行停止的应用无法依赖蓝牙广播唤醒；重新打开应用后恢复。这里自动建立的是耳机控制通道，系统音频配对与音频自动连接仍由手机蓝牙管理。详见 `自动连接与快捷磁贴说明.md`。

## ColorOS 流体云兼容测试

0.6.0 新增 Android 16 实时更新公开接口兼容，针对用户的 OPPO Find N2 / ColorOS16.0.5 提供测试版。进入右上角设置，检查“流体云连接提示”和“系统实时更新权限”，允许后断开并重新连接耳机。连接中展示真实连接任务，完成后展示约5秒电量与模式；点击进入主界面。四按钮通知栏功能继续保留。

是否提升为系统胶囊/流体云由手机系统决定，不能仅凭ColorOS版本认定支持。设置页能查看实际Android/API版本、接口存在性、通知授权与上次请求结果。该功能无需网络、悬浮窗或root权限。详见 `ColorOS流体云说明.md`。

## 安装与使用

安装 `dist/ZirconPods.apk`。使用原有包名和本机签名，可覆盖之前的 ZirconPods 版本。打开耳机盒，在系统蓝牙中配对；进入应用左上角设备面板，扫描并连接。首次使用授权附近设备与通知权限。连接后下拉通知栏，可切换降噪、风噪、通透和普通；展开可断开连接。

## 本次界面与功能

- 接入真正的 Miuix 0.2.9 Compose 组件库，使用 MiuixTheme、Card、SuperSwitch、SuperDropdown；选择菜单为右侧白色圆角浮层与蓝色勾选。
- 黑、银、紫三种耳机主图配色，选择保存在本地，仅改变展示主图。
- 主界面保留电量、四种噪声模式、超级大师调音、游戏模式、双设备连接与音频编码。
- 触控设置单独置于主界面，可设置触控开关，以及左右耳各自的单击、双击、三击与长按。
- 移除听力保护界面；提示音等级移至实验室。
- 实验室含入耳检测、提示音等级、极限降噪和降噪触控设置。极限降噪使用独立命令，关闭后切回普通模式。降噪触控循环至少选择两种模式。
- 重绘降噪、风噪、通透、普通、刷新、配对、应用与通知图标；箭头使用 Miuix 图标。实验室采用左右耳图标，不借用截图中其他耳机型号的产品照片。

耳机设置全部以真实回包确认，不会在点击后伪造设备状态。选项尚未上报时显示“未读取”。耳机已处于极限降噪时，主页和通知会明确显示该状态，四个基础模式不会错误高亮。

通知后台连接机制沿用0.4.0：离开主界面仍保持控制连接；耳机断开后移除通知。若通知未显示，在右上角设置中打开“通知栏控制设置”。

无网络权限。录音、翻译、AI、社区、在线升级不在本地控制范围内。

## 构建与验证

依赖固定为 AGP8.5.2、Kotlin2.0.21、Miuix0.2.9、Compose1.7.0、Gradle8.9；Android SDK platform34与build-tools36.0.0，JDK17+（本机使用JDK22）。

```powershell
.\build.ps1 -Online   # 首次构建需联网解析依赖
.\build.ps1           # 依赖已缓存后离线构建
.\test.ps1
```

构建脚本在ASCII临时目录中编译，避免Windows中文路径的Android打包问题。输出经签名和zipalign校验后保存到 `dist/`。源码包不包含 `.local/` 中的私钥与密码；首次构建会生成自己的本地签名，该签名无法覆盖本机原发布签名的安装包。原工作目录保留原签名用于后续覆盖更新。

161项主机测试通过（77协议、22通知状态、19连接弹窗生命周期/内容、43自动连接过滤及磁贴循环）。本机没有连接的Android设备或可用模拟器，尚未验证Find N2的磁贴展示、后台自动连接、原生流体云显示、系统提升标记、实际通知/浮层渲染、后台存活、触控、极限降噪和循环设置的实机行为。界面与素材说明见 `UI设计说明.md`，新增协议证据见 `实验室协议说明.md`。
