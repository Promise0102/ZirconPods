# 风格文件库与导入（0.11.0）

本次按用户选择接入“人声、低音等风格预设”。预设为有来源声明的通用听感参考，不是锆势专用测量校正，也不表示某种曲线适合所有音乐或听者。

## 内置风格

自定义 EQ 页新增独立的“风格文件库”：平直、人声增强、低音增强、流行、摇滚、古典柔和、舞曲节奏、低音与高音、高音明亮，共9个文本文件。

- 人声/低音：改编自 Equalizer314 `loadPreset` 风格公式，GPL-3.0；调整为本软件十个控制点，不是上游参数滤波器的精确响应。
- 其余7个：源于 VideoLAN VLC `equalizer_presets.h` 风格数组，LGPL-2.1-or-later；明确采用其旧版频率表，再转为本软件十段参考。
- 固定版本、版权声明、许可原文及修改说明见 `third_party/Equalizer314/UPSTREAM.md`、`third_party/VLC-presets/UPSTREAM.md`。APK的设置 → 开源许可也可查看。

选择风格会载入编辑区，并显示来源与转换说明；不会改变当前运行中的手机音效。可以继续修改、保存为本地预设，再按“应用本页曲线到手机 EQ”。原有用户预设独立保留，不因本次更新而覆盖或自动删除。

## 本地文件导入

点击“导入 GraphicEQ 文件”，通过系统文件选择器选择UTF-8文本。支持以下数据格式：

```text
# Name: 我的音效
# Source: 可选来源说明
# License: 可选许可声明
Preamp: -3 dB
GraphicEQ: 20 0; 100 2; 300 1; 500 0; 1000 2; 2000 1; 3000 0; 5000 -1; 8000 0; 15000 1
```

文件名仅作名称回退。支持BOM、CRLF、科学计数法和注释。一次只允许一条GraphicEQ曲线，2～512个严格递增频率点，频率1～48000Hz，原始增益绝对值不超过60dB，整个文件不超过128KiB。

不支持Equalizer APO参数`Filter`、JSON、卷积、`Include`或其他指令；遇到这些内容会拒绝整个文件，不会悄悄丢弃后应用。不会执行文件、打开其URL或读取它引用的其他文件。系统文件选择器不需要新增存储权限，应用仍无网络权限。

读取成功后先显示名称、文件声明来源、转换后十段数值和转换说明。用户确认“载入编辑区”后才替换草稿，仍需单独保存或应用到手机EQ；取消不影响当前音效。

## 转换边界

原始点按对数频率插值到20/100/300/500/1k/2k/3k/5k/8k/15kHz，超出源文件范围时保持端点。十段值若超过±6dB，整条十段曲线按同一比例缩放，再取整为1dB；比例会在界面提示。不是保留全部原始细节的无损导入。

文件Preamp仅记录在转换说明中，不直接改变手机音量或覆盖引擎的自动负增益余量。手机端EQ的播放器接入与听感仍需实测，导入成功不等于正在生效。
