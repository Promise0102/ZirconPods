# ZirconPods 0.8.1：通知透明背景修复

用户的 ColorOS 实机截图显示：系统毛玻璃通知里又套了应用绘制的白色卡片，左侧还有系统应用图标、顶部还有 ZirconPods 名称。

本版将折叠、展开通知使用的卡片/分组底色全部改为透明；圆角按钮改为半透明黑色（浅色模式）或半透明白色（深色模式）。耳机图片、ROSE Zircon 设备名称、电量、按钮和展开控制继续使用原有布局，透出的是 ColorOS 原本的通知背景，本应用不对文字或产品图片施加模糊。

左侧应用图标和顶部应用名称不属于自定义 RemoteViews。Android 12 及以上会为目标 API 31+ 的应用强制添加系统通知模板，普通应用没有公开接口删除这些标识或释放其占用区域。移除 DecoratedCustomViewStyle 也不能取消这项系统行为。本版保留真实的通知来源与正常目标 SDK，不以透明图标、伪造应用名称或降低 targetSdk 冒充已经删除系统外层。

流体云仍使用系统标准实时更新样式，连接完成后显示 10 秒且无模式/断开按钮；本次透明色修复只作用于自定义控制通知，不改变流体云的系统模板。

已检查浅/深色资源中的卡片背景 alpha 为 0、按钮 alpha 为 0x30，Android XML 可解析；发布 APK 进行签名和对齐校验。尚未在手机上检查本次透明样式的实际显示效果。协议、自动连接、磁贴和 10 秒计时逻辑未修改。

官方说明：[Android 12 自定义通知行为变化](https://developer.android.com/about/versions/12/behavior-changes-12#custom-notifications)、[自定义通知布局](https://developer.android.com/develop/ui/views/notifications/custom-notification)。
